# ⚖️ NyayaSaathi AI
> **Understand your rights, take the right action.**

NyayaSaathi AI is an accessible, AI-powered platform designed to bridge the gap between citizens and complex legal/civic information. We simplify government schemes, civic rights, and legal jargon into clear, actionable, and personalized steps. 

Built with a "Citizen First" approach, NyayaSaathi transforms confusion into a concrete plan of action, accessible to users with varying levels of digital literacy.

---

## 🌟 Our Unique Selling Proposition (USP)
Most legal tech platforms just provide overwhelming information. **NyayaSaathi focuses on Action.** 
Instead of dropping users into a wall of text, we provide personalized, step-by-step guidance. Coupled with **Native Multilingual Support (English, Hindi, Marathi)** and built-in tools like our **RTI Assistant** and **Document Analyzer**, NyayaSaathi is a comprehensive civic companion, not just a search engine.

## 🚀 Core Features
Our unified dashboard provides citizens with specialized tools for their specific needs:

*   **🤖 Ask AI:** Get immediate help with civic or legal issues in simple, easy-to-understand language.
*   **📋 Scheme Discovery:** Find and match with government schemes you actually qualify for.
*   **📄 Document Understanding:** Upload complex government or legal documents and let our AI break them down into plain language.
*   **✍️ RTI Assistant:** Step-by-step guidance to create and draft a Right to Information (RTI) application instantly.
*   **💾 Personalized Dashboard:** Track your recent activity, saved schemes, analyzed documents, and RTI drafts all in one place.

## 🛤️ How It Works (The 4-Step User Journey)
1.  **Tell Us Your Problem:** Describe your situation in plain, everyday language.
2.  **AI Understands:** NyayaSaathi analyzes the context and identifies the exact civic or legal topic.
3.  **Trusted Information:** We retrieve relevant data strictly from official and trusted sources.
4.  **Take Action:** The user receives a tailored, step-by-step action plan—from drafting an application to knowing exactly which office to visit.

## 💻 Tech Stack
This prototype is built for speed, responsiveness, and a smooth user experience.
*   **Frontend:** React 18 | Vite | Tailwind CSS | React Router | Lucide Icons  
*   **AI / Backend (Architecture):** Grounded RAG Pipeline | Vector Search | Intent Detection | LLM Generation
*   **Routing:** React Router DOM v6
*   **UI/Icons:** Lucide React

## 🛠️ Local Installation & Run Instructions
To run this prototype locally on your machine, follow these steps:

**Prerequisites:**
*   Node.js (v16 or higher)
*   npm (Node Package Manager)

**Steps to Run:**
1. Clone the repository:
   ```bash
   git clone https://github.com/AdityaBandal11/NyayaSaathi.git
   ```
2. Navigate into the project directory:
   ```bash
   cd nyayasaathi-ai
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```
4. Start the Vite development server:
   ```bash
   npm run dev
   ```
5. Open your browser and visit the local host link provided in your terminal (usually http://localhost:5173)
